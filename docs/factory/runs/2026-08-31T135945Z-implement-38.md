matcher rejects the URI unless **both** variables are present: `workitem://<id>/tree` and
`workitem://<id>/tree?depth=1` both return `Resource not found`. Every tree URI in this file
spells out both. Fixing it needs `src/` and is out of scope here; it is filed separately.
