## Note for factory tooling, not this PR

`.factory/scripts/prove-test.sh`'s non-test-file classifier does not know about
`docs/factory/runs/**`, so any test-only slice whose branch also carries its own run-record
commit will make the script misreport `FAILED reason=test-passed-without-fix` instead of
`MISCONFIGURED reason=no-non-test-change`. Worth a human's judgment on whether to teach the
script the `DOCS_NOT_COUNTED` globs, restrict it to files under `src/`, or something else —
not filed as an issue from inside this run.
